# Todo List Web Application(v2.0)

Spring BootとThymeleafを用いた、タスク管理Webアプリケーションの発展版(v2.0)です。
基本のCRUD操作（登録・取得・変更・削除）に加え、**タスクの集計（全件数・残り未完了件数）、条件抽出（フィルター）、期限日順の並び替え（ソート）、ファイル出力（CSV/TEXT出力）機能**を新たに実装し、使いやすさと利便性を向上させています。

---

## 技術スタック (Tech Stack)

- **Backend:** Java 17 (17.0.17), Spring Boot 3.3.5, Spring Data JPA
- **Frontend:** HTML, CSS, Thymeleaf, JavaScript (Confirm Dialog / Alert)
- **Database:** MySQL (XAMPP)
- **Development Environment:** Eclipse (Pleiades), Apache Tomcat (Spring Boot内蔵)

---

## 新機能・追加された仕様 (What's New in v2.0)

1. **タスクの集計・ステータス表示**
   - データベースに登録されている全タスク数をカウントして表示。
   - 未完了のタスクのみを自動で集計する countUndone メソッドを実装し、「残りタスク数」として表示。
2. **タスクの抽出（フィルター）機能**
   - 「期限前」「今日まで」「オーバー」「解除」の条件を選択し、該当するタスクだけを抽出して一覧表示。
   - 抽出された件数を画面上に反映。
3. **タスクの並び替え（ソート）機能**
   - 期限日を基準に、「昇順」「降順」への並び替えに対応。
4. **ファイル出力（CSV/TEXT出力）機能**
   - 全タスクのデータを日付付きファイル名でダウンロード可能。
5. **エラー防止機能：未選択（null）確認**
   - ラジオボタンの未選択時に対し、「null」チェックを行いエラー防止を徹底しています。
6. **エラー防止機能：try-catchによる例外処理**
   - ファイル出力においてエラーが発生したとき、エラーメッセージをログに残すことで原因を特定しやすくするよう記述。

## 操作説明（How to use this app）

1. **タスクの抽出（期限日でフィルター）**
   - ラジオボタンの「期限前」「今日まで」「オーバー」「解除」を選択し「抽出」ボタンを押すことで、該当するタスクだけが一覧表示されます。
2. **タスクの並び替え（期限日ソート）**
   - ラジオボタンの「昇順」「降順」「並び替え解除」を選択し「並び替え」ボタンを押すことで、期限日で並び替えて一覧表示されます。
3. **ファイル出力（CSV/TEXT出力）**
   - 「CSV出力」ボタン/「TEXT出力」ボタンを押すと、CSVファイル/TEXTファイルがダウンロードフォルダに作成されます。全タスクのデータが出力され、ファイル名は日付付きとなっています。

## アーキテクチャ・ファイル構成 (Architecture)

MVCモデルに則り、責務を明確に分離して設計しています。

- **Entity (`Todo.java`)**: データベースの `Todos` テーブルと1対1でマッピングされるエンティティクラス。JPQLによる名前付きクエリを定義。
- **DAO (`MyDAO.java` / `TodoService.java`)**: 共通のCRUD操作インターフェースを実装し、データベースの登録・取得・更新・削除処理を担当。
- **Controller (`TodoController02.java`)**: リクエストを受け付け、サービス層へ処理を委譲、画面（Model）へデータを渡す。
- **View (`todoList02.html`)**: Thymeleafを用いた動的なHTMLテンプレート。
- **Static Assets (`todo_style02.css`, ファビコン・アイコン)**: スタイルシートと画像リソース。
